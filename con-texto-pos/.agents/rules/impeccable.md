# Reglas de Diseño Impeccable

Cuando diseñes o modifiques componentes de interfaz en este proyecto:

1. **Jerarquía Visual y Claridad**: Todo elemento primario (acciones principales, números clave de caja/ventas) debe destacar sobre elementos secundarios sin recargar la pantalla.
2. **Cero AI Slop**: Evitar fondos beige genéricos, tarjetas anidadas excesivas y bordes redondeados desproporcionados. Usar la escala tipográfica Roboto responsiva.
3. **Impeccable Activo**: Recordar al desarrollador que el skill Impeccable está activo para auditar, pulir (`/polish`), simplificar (`/distill`) o estructurar (`/shape`) las vistas de la aplicación.
